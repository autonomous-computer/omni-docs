# Manage billing

TUROS bills successful production work. Test traffic, health checks, quotes, public discovery, and requests that fail before work starts are free. [Pricing and billing](/pricing) explains the commercial model; this page covers account operations and response behavior.

## Inspect the account

Use a live API key for the current organization's billing and limit state:

```bash
curl --fail-with-body -sS \
  -H "x-api-key: $SECAPI_API_KEY" \
  -H "secapi-version: 2026-03-19" \
  "https://api.secapi.ai/v1/billing"

curl --fail-with-body -sS \
  -H "x-api-key: $SECAPI_API_KEY" \
  "https://api.secapi.ai/v1/limits"
```

`GET /v1/billing/rates` returns the public rate catalog. `POST /v1/billing/quote` estimates a request but does not reserve credits or capacity.

## Included allowance

New organizations receive 100 included live calls. The allowance is confirmed; automatic monthly renewal is not. Treat exhaustion as a stop condition and inspect the live billing response instead of assuming a renewal date.

From 80% consumption onward, billable responses can return grant advisory headers including `SECAPI-Grant-Status`, `SECAPI-Grant-Consumed-Percent`, `SECAPI-Grant-Remaining`, and a next action. When the allowance is spent, `402 billing_required` identifies the cause in `details.reason`, such as `starter_grant_exhausted`.

## Wallet and top-ups

Pay as you go uses prepaid credits. The dashboard is the supported place to add a payment method, enable PAYG, buy credits, configure auto top-up, request an eligible refund, and set budget controls. These mutations require a signed-in dashboard session; an API key cannot change billing.

| Endpoint family | Purpose |
| --- | --- |
| `/v1/billing/credits` | Read the credit balance, low-balance state, and configured auto top-up. |
| `/v1/billing/credits/transactions` | Review top-ups, debits, refunds, grants, and adjustments. |
| `/v1/billing/budget` | Read or set spend caps and alert thresholds. |
| `/v1/billing/payment-methods` | Manage organization payment methods with a dashboard session. |

Paid credits do not expire under the current pricing model. Larger top-ups save up to 30%; see [pricing](/pricing) for the bands.

## Meters

Work is grouped into meter families such as light reads, standard reads, heavy extracts, artifact jobs, delivery events, intelligence queries, market-data reads, and semantic search. Preserve `SECAPI-Meter-Class` and `SECAPI-Estimated-Cost` when returned.

Named analysis jobs are billed once on successful completion. Enqueue responses, in-flight polls, failures, cancellations, and later reads of an already billed result do not create a second charge.

## Idempotency and billing errors

Send `Idempotency-Key` on billable POST requests. Reusing a key with a different body is rejected; an in-flight first call can return `409` with `Retry-After`.

For `402 billing_required`, branch on `details.reason`, not the human-readable message. Resolve the stated account condition before retrying.

## Rights boundary

Pay as you go covers evaluation and internal use. Redistribution, embedding, white-labeling, resale, bulk export, committed volume, and contractual service terms require Custom terms. A `200` response does not grant redistribution rights.
