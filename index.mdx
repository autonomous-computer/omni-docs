## One production contract

REST, MCP, SDKs, and the CLI use the same data layer, credentials, response conventions, and pay-as-you-go wallet. Production requests currently use `https://api.secapi.ai`. The `api.turos.app` host will become the default only after it passes the documented parity gate; existing integrations will continue to work.
