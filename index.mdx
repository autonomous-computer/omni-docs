# Omni Docs

Omni adapts the best parts of Craft Agents for financial intelligence workflows.

At a high level, Omni combines:

- A **financial terminal** with robust symbol lookup and market context
- A **portfolio intelligence platform** with Daily Briefing synthesis at 1M+ analyzed tokens per day
- A **synced portfolio tracker** with holdings, models, and factor diagnostics
- An **agentic chat runtime** with skills, tools, and permissioned execution

## Product Lens

Omni is pursuing high parity with Craft Agents while intentionally adapting for product fit:

- No workspace-first mental model in user-facing docs
- No GitHub Copilot support path
- Deeper financial data, model, and event intelligence coverage
