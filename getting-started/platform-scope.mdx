# OMNI Platform Scope

OMNI is designed as an integrated platform with four primary surfaces:

1. Financial terminal workflows
2. Portfolio intelligence workflows
3. Synced portfolio tracking workflows
4. Agentic chat execution workflows

## Core Product Surfaces

| Surface | Primary Outcomes |
|---|---|
| Terminal | Symbol lookup, market context, structured research inputs |
| Portfolio Intelligence | Daily Briefing, factor diagnostics, event synthesis |
| Portfolio Tracking | Holdings continuity, watchlists, model and performance context |
| Agentic Chat | Analysis, code execution, document creation, and tool orchestration |

## Intelligence Plane

OMNI runs a production intelligence pipeline that:

- Ingests market, factor, and event inputs
- Synthesizes Daily Briefing outputs at production token throughput
- Preserves structured context for follow-up analysis

## Agentic Runtime Plane

OMNI chat superpowers are backed by:

- Skill selection and runtime routing
- Tool registration and guarded execution
- Source permissions and preset enforcement
- Session-level context and artifact persistence

## Automation Plane

OMNI automation includes:

- Event-driven hooks
- Scheduled runs
- Label and status triggers
- Prompt and command actions with safety controls

## Product Direction

The docs are intentionally OMNI-first:

- No external product comparisons
- No external product dependency framing
- Focus on operational truth in OMNI runtime behavior
