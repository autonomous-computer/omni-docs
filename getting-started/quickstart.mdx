# Quickstart

Use this flow to experience OMNI as a financial terminal plus agentic analyst.

## 1. Sign in

Open [console.turos.app](https://console.turos.app) and authenticate.

## 2. Open agentic chat

Start from the terminal/chat surface and ask for live market context.

Example prompts:

- `What moved markets today?`
- `Summarize today's high-impact macro events.`
- `Explain NVDA's move using factors and news.`

## 3. Validate symbol lookup

Run a symbol search flow:

- `Search symbols for 'Berkshire'`
- `Load BRK.B profile and key metrics`

OMNI uses first-party symbol tools for both exact and fuzzy lookup.

## 4. Pull a briefing

Ask for the latest briefing or specific date/type:

- `Show today's Daily Briefing`
- `List weekly briefings from the last 30 days`

## 5. Check portfolio intelligence

Ask for portfolio and holdings diagnostics:

- `Show portfolio summary and YTD`
- `Run holdings pulse in compact mode`
- `Show factor decomposition for AAPL`

## 6. Try a Superpower workflow

Use skills for deeper tasks:

- `Run read-news for semiconductors and cluster themes`
- `Build a draft investment thesis for MSFT`
- `Analyze this PDF and extract the key tables`
