Fund Letters will add manager commentary to [Track Investors](/workflows/track-investors): permitted investor letters, company mentions, theses, changes in stated views, and page-level citations alongside SEC-reported holdings and ownership disclosures.

<Warning>
Fund Letters is not publicly available today. The public API and MCP plane remains gated. Routes may appear in OpenAPI while the capability is unavailable; documentation is not an availability signal.
</Warning>

Check `availability` in the [API catalog](https://www.turos.app/docs/.well-known/api-catalog.json) before you treat a `404` as a missing record.

## Planned workflow

When access opens, the capability is intended to answer bounded questions such as:

- Which permitted letters exist for a manager, fund, company, or period?
- Where did a manager discuss a company or theme?
- How did a stated thesis change between letters?
- How does stated commentary compare with later reported 13F holdings?

Results are designed to retain the letter identity, publication or as-of date, document location, and page-level citation needed to review the original passage.

## Coverage boundary

Initial documented coverage begins with Q1 2025 and is not a comprehensive historical archive. Coverage will depend on permitted documents, manager and fund identity resolution, extraction quality, and distribution rights. Do not assume that a missing result means a manager did not publish or discuss something.

## Availability

When selected customers can use the capability, this page will change from **Coming Soon** to **Preview** and document the actual access path. Until then:

- do not build a production dependency on fund-letter endpoints;
- do not present letters as generally available through MCP;
- check the live API catalog for current capability status; and
- use 13F and 13D/13G data for the available Track Investors workflow.

Continue to [Track Investors](/workflows/track-investors) or [SEC Filing Data](/filings/overview).
