# Portfolio Intelligence

Omni combines portfolio tracking with analytical reasoning and execution context.

## Portfolio layer

Core portfolio tools include:

- `omni_api_get_portfolio`
- `omni_api_get_portfolio_history`
- `omni_api_get_holdings_pulse`

These provide P&L, net liquidation, holdings-level diagnostics, and performance windows.

## Model intelligence layer

Model-level workflows include:

- `omni_api_get_model_performance`
- `omni_api_get_model_intel`
- `omni_api_get_model_factor_exposure`

This enables return attribution and constituent-contribution analysis by model slug.

## Operational layer

Portfolio workflows connect with:

- Watchlists and alerts
- Session labels/status workflows
- Agentic synthesis for recurring monitoring narratives

## Sync model

Omni uses local-first persistence with backend sync patterns for low-latency interaction and cross-session continuity.
