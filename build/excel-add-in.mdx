Bring supported TUROS data and repeatable analysis into the workbook where you already model investments. The add-in is an Alpha: interfaces, supported functions, and availability can change while the workflow is refined with early users.

## What the Alpha is for

- Resolve companies and identifiers without maintaining lookup tables.
- Retrieve filing-derived facts and supported company data into cells.
- Refresh repeatable analysis without copying results between tools.
- Keep source identifiers with workbook outputs so another analyst can verify them.

## Request access

[Create a TUROS account](https://www.turos.app/signup), then request Excel Alpha access from the product. Use test credentials while evaluating supported workbook functions. Excel uses the same TUROS account and pay-as-you-go wallet; it is not a separately priced data product.

<Warning>
Do not build a production workbook around an undocumented Alpha function. Confirm the current function catalog, input shape, and refresh behavior in the add-in before relying on it.
</Warning>

## Workbook safety

Keep credentials outside cells, preserve source and refresh metadata, review proposed model changes before applying them, and retain a restorable copy of important workbooks. For API-based automation outside Excel, use the [TUROS API](/build/api) or a supported [SDK](/build/sdks).
