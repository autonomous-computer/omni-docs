## Compatibility names

Current package names, environment variables, and the SDK default base URL still use `secapi`. Keep those identifiers exactly as documented; they are compatibility contracts, not stale branding. The production host is `https://api.turos.app`; `https://api.secapi.ai` is a permanently supported compatibility alias, so SDK defaults that still point at it keep working. New examples use `api.turos.app`.

## Production checklist

1. Build with a `secapi_test_…` key.
2. Store keys outside source code and prompts.
3. Pin the API version.
4. Set bounded timeouts and retries.
5. Preserve request and source identifiers.
6. Quote expensive work and set a budget before switching to a live key.

Start with the language guide above or use the [TUROS API directly](/build/api).
