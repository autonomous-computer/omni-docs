# Troubleshooting

## Chat not responding

Check:

1. Agent backend health endpoint
2. Auth token/session validity
3. Model provider key configuration

## Source connection issues

For MCP/API sources:

1. Verify source config and transport
2. Test source connection before enabling
3. Confirm OAuth credentials (if applicable)

## Missing market/news/factor results

1. Validate OMNI API connectivity
2. Confirm requested ticker/date parameters
3. Check whether requested endpoint/tool is enabled in preset/permissions

## Briefing data appears stale

Briefing/snapshot pipelines can have publication windows.

- Check latest available briefing date/type
- Re-run with explicit date to confirm availability

## Skill output quality is inconsistent

1. Confirm the right skill is being selected
2. Narrow prompt scope and desired output shape
3. Verify required sources/tools are available

## Still blocked?

Share:

- Prompt + timestamp
- Session ID
- Source and permission mode
- Any tool error payload shown in chat

For docs deployment errors, include the deployment check run ID and the failing log snippet.
