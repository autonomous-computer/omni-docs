# Icons

OMNI icon systems prioritize execution clarity and workflow speed.

## Tool Icon Mapping

Tool icon mappings are centralized in:

- `apps/omni-web/lib/tool-icons/data.ts`

Each mapping includes:

- tool ID
- display name
- icon asset
- command aliases

## Status Icon Options

Status icons can be:

- Emoji
- URL-fetched images
- Local files discovered by status ID

## Best Practices

- Keep icon mapping deterministic
- Avoid multiple conflicting icons for same command family
- Prefer recognizable ecosystem logos for command tools
