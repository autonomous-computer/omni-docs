Build issuer research views from SEC-derived statements, ratios, segments, macro exposure, and company snapshots. Every value traces back to a filing; keep the returned periods, units, and provenance with derived work.

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/v1/companies/overview` | Company overview. |
| `GET` | `/v1/companies/financials` | Company financial statements. |
| `GET` | `/v1/companies/income-statements` | Retrieve an issuer's income statement history with normalized operating and per-share fields. |
| `GET` | `/v1/companies/balance-sheets` | Retrieve an issuer's balance sheet history with normalized cash, debt, and equity fields. |
| `GET` | `/v1/companies/cash-flow-statements` | Retrieve an issuer's cash flow statement history with normalized cash-generation fields. |
| `GET` | `/v1/companies/ratios` | Retrieve statement-derived profitability, return, valuation, dividend, and leverage ratios with period context. |
| `GET` | `/v1/companies/segments` | Company segments. |
| `GET` | `/v1/companies/subsidiaries` | Company subsidiaries. |
| `GET` | `/v1/companies/audit-fees` | Company audit fees. |
| `GET` | `/v1/companies/macro-exposure` | Retrieve a revenue-weighted macro-exposure snapshot built from disclosed geographic revenue and country indicators. |

`GET /v1/companies/segments` is beta; its responses carry `SECAPI-Maturity: beta`. Treat beta fields defensively.

Before comparing values across periods, check `periodBasis` where the route provides it: balance-sheet values are point-in-time, while quarterly income-statement and cash-flow values can be year-to-date as filed. Compare units, reporting periods, and source context before treating values as comparable.

`GET /v1/companies/overview` supports `include=factors` as an opt-in expand of factor enrichments. See the [Introduction](/api-reference) for authentication, pagination, and error behavior.
