Price a channel-neutral operation before execution across API, MCP, CLI, SDK, Excel, and Sheets. This call returns quote and budget context; it does not settle usage.

<Info>
Audience: application and coding agent.
</Info>

## Canonical metadata

- `requestId`
- `traceparent`

## Example request

<RequestExample>
```bash
curl -X POST \
  -H "x-api-key: $SECAPI_API_KEY" \
  -H "secapi-version: 2026-03-19" \
  -H "content-type: application/json" \
  -d '{"operationId":"filing_model.fact.lookup","surface":"excel","meterClass":"fact_lookup","units":1}' \
  "https://api.secapi.ai/v1/operations/quote"
```
</RequestExample>
