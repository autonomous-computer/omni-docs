Operations endpoints help clients price and reserve channel-neutral work before execution. Use them when an agent, API client, CLI, SDK, Excel workbook, or Sheets integration needs to check availability, budget impact, and settlement posture before running the underlying operation.

<Note>
The pages in this family describe the quote and reservation envelope. They do not execute the underlying research operation unless that operation page and the response explicitly say so.
</Note>
