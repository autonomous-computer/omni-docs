---
title: "Filings"
description: "Search SEC filing records, then retrieve, extract, download, export, or render a selected filing."
---

Search SEC filing records, then move from a result into retrieval, section extraction, download, export, or a rendered view. Start with `GET /v1/filings` when you have an issuer, form, date, or query; use an accession-number lookup once you know the record.

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/v1/filings` | List filings. |
| `GET` | `/v1/filings/latest` | Latest filing. |
| `GET` | `/v1/filings/latest/render` | Render latest filing. |
| `GET` | `/v1/filings/latest/sections/{section_key}` | Latest filing section. |
| `GET` | `/v1/filings/latest/risk-categories` | Risk factor categories. |
| `GET` | `/v1/filings/{accession_number}` | Get filing by accession. |
| `GET` | `/v1/filings/{accession_number}/sections/{section_key}` | Filing section by accession. |
| `GET` | `/v1/filings/{accession_number}/download` | Download filing document. |
| `GET` | `/v1/filings/{accession_number}/export` | Export filing. |
| `GET` | `/v1/filings/pension-benefit-schedule` | Pension benefit schedule. |

Retrieve the latest 10-K for an issuer:

```bash
curl --fail-with-body -sS \
  -H "x-api-key: $SECAPI_API_KEY" \
  -H "secapi-version: 2026-03-19" \
  "https://api.secapi.ai/v1/filings/latest?ticker=AAPL&form=10-K&view=agent"
```

Latest-filing results are time-dependent - the accession number changes when a newer filing arrives. Preserve `accessionNumber`, `form`, `filingDate`, `filingUrl`, and `requestId` when the response includes them; they are the citation that identifies the source.

Filing retrieval and search are metered as standard reads; section extraction, comparisons, and document retrieval are heavy extracts. Coverage is a nine-year searchable floor with completeness checks for required forms for the two most recently completed years, and the current year as filings arrive.
