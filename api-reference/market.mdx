---
title: "Market"
description: "Market calendars, security reference data, price history, and latest-price snapshots."
---

Market routes serve trading calendars, security reference metadata, daily price history, corporate actions, and stored latest-price snapshots. Market reads are metered as `market_data_reads`.

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/v1/market/search` | Search securities. |
| `GET` | `/v1/market/reference` | Security reference data. |
| `GET` | `/v1/market/bars` | Daily price bars. |
| `GET` | `/v1/market/snapshots` | Latest price snapshots. |
| `GET` | `/v1/market/corporate-actions` | Splits and dividends. |
| `GET` | `/v1/market/calendar` | Market trading calendar. |

Snapshots are stored latest prices, not a live quote stream. Record retrieval time with any snapshot you persist.

See the [Introduction](/api-reference) for authentication, pagination, and error behavior.
