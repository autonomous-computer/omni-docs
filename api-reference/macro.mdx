---
title: "Macro"
description: "Country macro indicators, releases, forecasts, regimes, and sovereign credit ratings with revision-aware provenance."
---

Macro routes serve official-source country indicators, release calendars, forecasts, regime classifications, and sovereign credit ratings. Coverage is deepest for US, CN, JP, TW, and IL; CA, GB, EZ, KR, BR, IN, and SA carry a narrower set of high-signal indicators. Macro reads are metered as `market_data_reads`.

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/v1/macro/overview` | One-call country macro dashboard: headline indicators (latest, previous, change, direction, next release), current regime, upcoming releases, and sovereign credit rating. |
| `GET` | `/v1/macro/indicators` | Macro indicator observations. |
| `GET` | `/v1/macro/releases` | Macro data releases. |
| `GET` | `/v1/macro/calendar` | Macro event calendar. |
| `GET` | `/v1/macro/forecasts` | Return forecast baselines and scenario-aware macro projections with methodology metadata. |
| `GET` | `/v1/macro/regimes` | Return the current macro regime classification for a country. |
| `GET` | `/v1/macro/credit-ratings` | Return sovereign credit ratings for tracked countries and G20 members. |
| `GET` | `/v1/macro/credit-ratings/{country}` | Country credit rating. |
| `GET` | `/v1/macro/high-signal-pack` | Compact high-signal macro pack for one country, with source, fallback, and release-calendar metadata. |
| `GET` | `/v1/macro/search` | Search macro indicators. |
| `GET` | `/v1/macro/all` | Bulk macro observations. |
| `GET` | `/v1/macro/status` | Return macro data freshness, source metadata, and per-country support status. |

Observations carry revision-aware provenance - keep the source and revision metadata with any stored value, and check `GET /v1/macro/status` before treating a country as fully supported.

See the [Introduction](/api-reference) for authentication, pagination, and error behavior.
