Special situations are filing-derived corporate events: M&A, tender offers, going-private transactions, spin-offs, activist campaigns, restructurings, and bankruptcies. TUROS tracks each situation's current state and its filing trail, and publishes an immutable weekly digest.

You can browse situations publicly without an account, embed the public feed on your own site without a key, or call the paid API for sustained research and monitoring.

## Browse situations publicly

The public situations browser on [turos.app](https://turos.app) shows current situations with lifecycle status and links to the underlying SEC filings. No account or API key is required to browse.

## Embed the public preview

The `/v1/embed/situations` routes are a free, anonymous preview built for public sites and browser embeds. They are CORS-enabled and return public cache headers. Don't send an API key to these routes:

```bash
curl -sS "https://api.secapi.ai/v1/embed/situations?types=merger&limit=10"
```

The preview also includes a public event feed, an RSS feed, digest issue archives, per-situation detail and Markdown briefs, and a drop-in widget script that renders the situations feed into an element on your page. See the embed routes in the [Situations API reference](/api-reference/situations).

The preview is intentionally limited to a capped, recent public projection. It's a discovery surface, not a research dataset.

## Upgrade to the paid API

For an application, agent, or sustained monitoring workflow, create an API key in the TUROS dashboard and call the `/v1/situations` routes from your server. The paid API adds full filtering, per-situation filing timelines, calendars of disclosed dates, aggregate stats, closed-situation performance cohorts, underwriting packs, and watchlist monitors. Never put a paid API key in browser-delivered code.

| Use case | Route family | Access |
| --- | --- | --- |
| Public site or lightweight browser preview | `/v1/embed/situations` | Anonymous, CORS-enabled, capped |
| Application, agent, or sustained monitoring | `/v1/situations` | Paid, server-held `x-api-key` |

## Current detail vs. digest issues

A situation's current detail changes as new filings arrive. A weekly digest issue is an immutable publication-time snapshot and never changes. Keep the two distinct in a research record: cite an issue when you need what was known at publication, and current detail when you need the latest state.

## Decision boundaries

Situations are filing-derived. A situation record doesn't confirm that a transaction will close or that a disclosed date, term, or status remains current. Review the underlying filing before relying on any term or date in a decision, and keep the filing identifiers and request ID with derived output. Coverage is limited to SEC filing-derived situations - a missing situation is not proof that no related event exists.
