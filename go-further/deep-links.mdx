# Deep Links

OMNI supports URL-driven navigation for session and view targeting.

## Common patterns

- `?session=<id>`: open a specific chat session
- `?new=1`: force-create a fresh session
- `?filter=...`: open filtered session lists

## Examples

- `/terminal?session=<session-id>`
- `/chat?filter=archived`
- `/briefings/archive`

## Usage guidance

Use deep links in handoffs, automation outputs, and runbooks so recipients land directly in the relevant context.
