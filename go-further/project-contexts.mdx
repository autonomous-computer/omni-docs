# Project Contexts (No Workspaces)

OMNI keeps context session-first, so you can start work immediately without managing workspaces or folder structure.

## How OMNI builds context

OMNI composes context from:

- Session metadata and state
- Enabled sources and permissions
- User preference/profile context
- Attached files and extracted artifacts

## Why this matters

You can move between symbols, models, and event threads without “resetting” your environment. The session captures what you are working on and which tools are enabled.

## Practical outcome

Think in terms of:

- "What question am I answering?"
- "Which sources should be enabled?"
- "Which outputs should be persisted for follow-up?"
