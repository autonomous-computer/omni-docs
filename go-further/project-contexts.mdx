# Project Contexts (No Workspaces)

OMNI centers context around analysis objective and data scope.

## What OMNI uses

OMNI composes context from:

- Session metadata and state
- Enabled sources and permissions
- User preference/profile context
- Attached files and extracted artifacts

## Why this change

For OMNI's product direction, context is centered on **analysis objective + data scope**, not folder ownership.

This reduces setup friction and better matches financial research workflows that span symbols, models, and event threads.

## Practical outcome

Think in terms of:

- "What question am I answering?"
- "Which sources should be enabled?"
- "Which outputs should be persisted for follow-up?"
