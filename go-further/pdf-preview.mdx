# PDF Preview

PDF preview supports document-heavy diligence and reporting workflows.

## Typical Uses

- Review uploaded filings/reports
- Verify generated PDF artifacts from automation
- QA page structure before distribution

## Workflow

1. Acquire PDF (upload or generated artifact)
2. Render inline for fast review
3. Open fullscreen for detailed inspection
4. Confirm readability and pagination

## Best Practices

- Keep generated files under practical size limits
- Ensure embedded fonts for portability
- Validate table rendering on key pages

## Troubleshooting

- Render failure: verify file integrity and MIME type
- Cropped pages: check PDF page box settings
- Slow load: reduce asset weight in generated docs
