# Sharing Conversations

Omni sessions are designed for collaborative reasoning, even when full public-link sharing is tightly controlled.

## Current sharing patterns

- Share session context via URL/deep links
- Share generated outputs (briefings, summaries, artifacts)
- Reuse session labels/status to hand off work internally

## Best practices

- Include explicit scope in the final assistant turn
- Pin key citations and tool outputs in the handoff message
- Use labels to mark ownership and follow-up state

## Security note

Treat sessions as potentially sensitive financial research context unless explicitly designated for broad distribution.
