# Connect To Anything

OMNI is designed to connect to heterogeneous systems while preserving execution safety.

## Integration strategy

1. **Prefer first-party OMNI tools** for stable financial workflows
2. Add **MCP sources** for external tool ecosystems
3. Add **OAuth/API sources** for provider-specific capabilities
4. Use **custom endpoints** only when bounded and permissioned

## Practical examples

- Add an MCP source for your internal research tools
- Add OAuth-backed sources for productivity workflows
- Route market and news workflows through first-party OMNI APIs where possible

## Safety model

Always combine new integrations with:

- Permission mode controls
- Source-specific allow/deny rules
- Session-level approval where needed
