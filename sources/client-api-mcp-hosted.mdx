# Hosted MCP Protocol

OMNI’s official hosted MCP endpoint is:

```text
https://api.omnibrief.app/mcp
```

Compatibility endpoint:

```text
https://api.omnibrief.app/sse
```

## Transport model

- Primary: streamable HTTP (`/mcp`)
- Compatibility: SSE (`/sse`) for clients expecting legacy event stream bootstrap

## Authentication

All requests require:

```http
Authorization: Bearer omni_live_...
```

For `tools/call`, include:

```http
Idempotency-Key: <unique-per-call>
```

## Supported methods

| Method | Description |
| --- | --- |
| `initialize` | Handshake and capability negotiation. |
| `ping` | Connectivity health check. |
| `tools/list` | Enumerate OMNI MCP tools. |
| `tools/call` | Invoke a specific tool with arguments. |
| `notifications/initialized` | Initialization notification (no `id`). |

## Example sequence

1. `initialize`
2. `notifications/initialized`
3. `tools/list`
4. `tools/call`

## Tool parity policy

Hosted MCP tool behavior maps to OMNI Client API semantics:

- same auth model
- same rate limits and quotas
- same request ID behavior
- same billing semantics (`2xx/3xx` billable, failures non-billable)

## Current tools

- `fred.search`
- `fred.series`

## Session behavior

- `MCP-Session-Id` header is returned for hosted transport sessions.
- `DELETE /mcp` closes the active session context.

## Official adapters (internal beta)

During internal beta, we ship first-party adapters to make MCP integration trivial.

### JavaScript (`@omni/omni-mcp-js`)

Install:

```bash
pnpm add @omni/omni-mcp-js
```

Usage:

```ts
import { OmniMcpClient, OmniMcpError } from "@omni/omni-mcp-js";

const client = new OmniMcpClient({
  apiKey: process.env.OMNI_API_KEY!,
  // baseUrl: "https://api.omnibrief.app",
  // omniVersion: "2026-02-17",
});

await client.initialize();

try {
  const result = await client.callTool("fred.search", { q: "inflation", limit: 5 });
  console.log(result.structuredContent);
} catch (err) {
  if (err instanceof OmniMcpError) {
    // Use requestId to correlate with OMNI logs / support.
    console.error(err.kind, err.status, err.requestId, err.message);
  }
  throw err;
}
```

### Python (`omni-mcp-py`)

Install:

```bash
pip install omni-mcp-py
```

Usage:

```python
from omni_mcp_py import OmniMCPClient, OmniMCPError

client = OmniMCPClient(api_key="omni_live_...")

client.initialize()

try:
    result = client.call_tool(
        name="fred.search",
        arguments={"q": "inflation", "limit": 5},
    )
    print(result.get("structuredContent"))
except OmniMCPError as exc:
    print(exc.kind, exc.status_code, exc.request_id, str(exc))
    raise
```
